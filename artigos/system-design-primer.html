The System Design Primer

Guia · Donne Martin · 2017

#System Design

Um mapa gratuito e organizado dos blocos de construção de sistemas grandes, com exercícios no estilo de entrevista.

Resumo

O System Design Primer é um repositório no GitHub que reúne, num só lugar, os conceitos que aparecem sempre que se projeta um sistema para muitos usuários. Ele começa pelos trade-offs fundamentais (desempenho × escalabilidade, latência × throughput, teorema CAP) e percorre os componentes um a um: DNS, CDN, balanceadores de carga, proxy reverso, camada de aplicação, bancos de dados (replicação, federação, sharding, SQL × NoSQL), cache, filas e processamento assíncrono, e protocolos de comunicação.

Cada seção é curta e aponta para leituras mais profundas, muitas delas artigos como os desta lista. No fim, há exercícios resolvidos passo a passo (projetar um Pastebin, a timeline do Twitter, um web crawler…) e flashcards para revisar.

Por que importa

  • É um ótimo ponto de partida: dá o vocabulário para entender os papers mais densos.
  • Organiza um assunto espalhado em um roteiro de estudo, com referências para cada tópico.
  • É uma das referências mais usadas para se preparar para entrevistas de system design.
