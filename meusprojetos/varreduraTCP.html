Demonstração do scanner.

Uso ético: varrer portas de máquinas que você não administra, sem autorização, é intrusivo e pode ser ilegal. O projeto é para estudo, em hosts próprios ou com permissão explícita.

A ideia

Ferramentas como o Nmap fazem muito mais, mas construir um scanner do zero ajuda a entender o que acontece por baixo: um handshake TCP que se completa significa que há um serviço escutando naquela porta. O objetivo foi praticar sockets e redes com um código curto e fácil de ler.

Como funciona

  1. ArgumentosAlvo (IP ou hostname), porta inicial e porta final.
  2. Tabela de serviçosCarrega ports_services.csv com portas conhecidas.
  3. ConexãoPara cada porta, tenta um connect_ex() com timeout de 0,5 s.
  4. ResultadoSe retornar 0, a porta está aberta: imprime protocolo, serviço e descrição.

Uso

$ python portscan.py 192.168.0.10 1 1024

O núcleo da varredura

O connect_ex() devolve um código de erro em vez de lançar exceção: 0 significa conexão aceita. O timeout curto evita ficar preso em portas filtradas, e o finally garante que todo socket seja fechado. 

for port in range(portInitial, portEnd + 1):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)   # IPv4 + TCP
    s.settimeout(0.5)
    try:
        if s.connect_ex((alvo, port)) == 0:
            # procura a porta na tabela do CSV; senão, "Desconhecido"
            ...
    finally:
        s.close()

Tabela de serviços

O CSV traz 39 portas comuns (FTP, SSH, Telnet, HTTP, HTTPS, bancos de dados…) no formato Port,Protocol,Service,Description. A leitura ignora linhas incompletas ou com porta não numérica, então o arquivo pode ser editado à mão sem quebrar o programa.

Próximos passos

  • Varredura concorrente com ThreadPoolExecutor ou asyncio: hoje as portas são testadas uma de cada vez, então um intervalo grande de portas filtradas pode levar muito tempo (até 0,5 s cada).
  • Carregar o CSV num dicionário (porta → serviço) para consulta em O(1), em vez de percorrer a lista a cada porta aberta.
  • Usar argparse para validar o intervalo (1–65535) e aceitar opções como timeout e listas de portas.
  • Banner grabbing: ler a primeira resposta do serviço para identificar versão, além do nome esperado da porta.
