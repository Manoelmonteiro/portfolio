A ideia

O projeto nasceu no hackathon HackAIA (maio de 2026) como uma forma de ensinar o patrimônio cultural sergipano (festas, danças, patrimônios materiais e imateriais, personalidades e até o “sergipanês”) de um jeito que funcione numa aula de verdade: partidas curtas, pontuação, competição saudável entre os alunos e acessibilidade desde o início.

Depois do hackathon reescrevi praticamente tudo: catálogo de dados único, API validada e testada, jogos com lógica nova e uma interface inteira no padrão Material Design 3.

Os jogos

Onde Fica?

Lê uma pista e toca no mapa de Sergipe onde a manifestação acontece. A pontuação depende da distância real, em km, até a cidade certa.

Material ou Imaterial?

Classificar patrimônios arrastando o card, pelos botões ou pelas setas do teclado. A cor do card não entrega a resposta.

Aprenda Cultura

Lições curtas em níveis, com múltipla escolha e verdadeiro/falso, dicas e explicação depois de cada resposta.

Wiki Sergipana

Busca por nome, cidade ou descrição, filtros por categoria, link direto para cada item e envio de novos conteúdos.

Arquitetura

O front-end é HTML, CSS e JavaScript puro, sem etapa de build. Um único catálogo (dados.js) alimenta a home, a wiki e os jogos, e um núcleo compartilhado (app.js) cuida de layout, acessibilidade, sessão, pontuação e chamadas à API. A API em FastAPI cuida de professores, turmas, alunos, partidas, quiz e ranking.

Destaques técnicos

Pontuação pela distância real

No Onde Fica?, o contorno de Sergipe e as cidades são desenhados num SVG com uma projeção equirretangular local. O clique é convertido de volta para longitude e latitude, e a distância até a cidade certa é calculada com a fórmula de haversine. Até 15 km vale 30 pontos, até 35 km vale 20, e até 60 km o jogo avisa que foi quase. 

const FAIXAS = [

function distanciaKm([lon1, lat1], [lon2, lat2]) {
  const R = 6371;   // raio da Terra em km
  const rad = d => (d * Math.PI) / 180;
  const dLat = rad(lat2 - lat1);
  const dLon = rad(lon2 - lon1);
  const a = Math.sin(dLat / 2) ** 2 +
            Math.cos(rad(lat1)) * Math.cos(rad(lat2)) * Math.sin(dLon / 2) ** 2;
  return 2 * R * Math.asin(Math.sqrt(a));
}

Uma API que não confia no cliente

Todas as entradas passam por modelos Pydantic com limites (por exemplo, de 1 a 50 questões e pontos não negativos), e partidas com números incoerentes são rejeitadas. No quiz, o gabarito fica no servidor: o aluno responde uma questão por vez, e responder a mesma questão de novo devolve 409. 

if resposta.aluno_id != sessao["aluno_id"]:
    raise HTTPException(status_code=403, detail="Aluno não pertence a esta sessão.")
if resposta.questao_id not in sessao["questoes_ids"]:
    raise HTTPException(status_code=400, detail="Questão não pertence a esta sessão.")
if resposta.questao_id in sessao["respostas"]:
    raise HTTPException(status_code=409, detail="Esta questão já foi respondida.")

Testes e deploy automatizados

Onze testes com pytest cobrem o fluxo completo do quiz, a validação de campos, a entrada de alunos, o ranking e os erros 404. Dois workflows do GitHub Actions rodam os testes a cada push e publicam a pasta public/ no GitHub Pages. Na Vercel, o vercel.json serve o front e encaminha /api/* para a FastAPI.

Acessibilidade e Material Design 3

O menu de acessibilidade tem modo TEA (menos animação e estímulo visual), alto contraste e ajuste do tamanho da fonte, com as preferências salvas no navegador. O tema escuro acompanha o sistema. A interface usa tokens de cor, tipografia, forma e elevação do Material 3 em variáveis CSS, com cor-semente verde inspirada na bandeira de Sergipe, e todo conteúdo dinâmico passa por escape de HTML antes de ir para a página.

Limitações e próximos passos

  • A API guarda tudo em memória. Em serverless, os dados somem quando a instância reinicia; o próximo passo é ligar um banco de dados antes de usar com turmas reais.
  • No GitHub Pages só roda o front: os jogos funcionam offline, mas turmas e ranking precisam da API publicada na Vercel.
  • Autenticação de professores e moderação dos conteúdos enviados para a wiki.
