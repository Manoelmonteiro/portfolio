O problema

Aulas, palestras e tutoriais longos tomam tempo, e muitas vezes você só quer saber se vale a pena assistir ou relembrar os pontos principais. A ideia foi automatizar o caminho vídeo → texto → resumo numa interface web simples, sem precisar abrir o terminal.

Como funciona

  1. URLO usuário cola o link no front-end React, que faz um POST /processar.
  2. DownloadO back-end baixa o vídeo com pytubefix na maior resolução disponível.
  3. TranscriçãoO MP4 é enviado ao whisper-large-v3-turbo da Groq.
  4. ResumoO texto vai para o groq/compound com o pedido de resumir no mesmo idioma.
  5. RespostaA API devolve JSON e o React mostra o resumo na tela.

Estrutura do repositório.

API

O back-end é pequeno de propósito: um modelo Pydantic valida a entrada e um único endpoint chama o pipeline. O CORS está liberado para o front-end, que roda em outra porta durante o desenvolvimento. 

class Video(BaseModel):
    url: str

@app.post("/processar")
def processar_video(video: Video):
    resultado = baixa_transcreve(video.url)
    return {"resultado": resultado}

backend/main.py

Pipeline de IA

Cada etapa é uma função separada (baixa_Video, procura_mp4, transcreve_Audio, explica_Audio), e baixa_transcreve encadeia tudo. A chave da Groq é lida de um arquivo .env com python-dotenv; se ela não existir, o código levanta um erro claro em vez de falhar no meio da chamada. 

transcription = api_client.audio.transcriptions.create(

Interface

O front-end em React tem um único formulário com estado de carregamento (spinner e botão desabilitado enquanto processa) e mostra o resumo assim que a API responde. O visual usa tema escuro com fundo animado.

Telas

Desafios e aprendizados

Do terminal para a web

A primeira versão só imprimia o resultado no terminal. Trocar print() por return foi o que permitiu expor o pipeline como API.

CORS e integração

O navegador bloqueava as chamadas do React para o FastAPI até a configuração do CORSMiddleware.

Chaves de API

Erros 401 e variáveis de ambiente ausentes levaram a centralizar a configuração num .env fora do versionamento.

Ambiente

O Vite exigiu Node 20+, e o fluxo de branches develop → main trouxe a prática de resolver conflitos de merge.

Próximos passos

  • Baixar só o áudio em vez do vídeo na maior resolução: o arquivo fica bem menor e a transcrição é mais rápida.
  • Um diretório temporário por requisição, para que cada pedido transcreva o próprio arquivo e não o primeiro .mp4 da pasta.
  • Concluir o login (branch feat/login), trocando a verificação simulada por usuários num banco e tokens reais.
  • Resumos curto e longo, exportação em PDF e histórico de vídeos processados.
